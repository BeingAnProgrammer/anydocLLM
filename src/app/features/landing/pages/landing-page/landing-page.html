Frequently asked questions.

What is AnyDoc LLM?

AnyDoc LLM is a free, open-source tool that converts documents into clean, LLM-ready Markdown entirely inside your browser — no account, no upload, no server round-trip.

How do I convert a PDF to Markdown?

Open the converter, drop in a PDF, and AnyDoc LLM extracts its text and structure into Markdown you can preview, copy, or download.

Can I convert DOCX to Markdown?

Yes. DOCX and legacy DOC Word documents are both supported.

Can I convert Excel files to Markdown?

Yes. XLSX and legacy XLS spreadsheets convert to Markdown tables.

Does AnyDoc LLM require an API key?

No. There's no API and no configuration — conversion runs locally using WebAssembly.

Are my files uploaded to a server?

No. Documents are parsed entirely in your browser tab; they are never uploaded or sent anywhere.

Is AnyDoc LLM free?

Yes. AnyDoc LLM is free to use, with no subscription or paid tier.

Is AnyDoc LLM open source?

Yes. The source code is publicly available on GitHub.

Which document formats are supported?

PDF, DOCX, DOC, XLSX, XLS, PPTX, PPT, CSV, ODT, ODS, ODP, RTF, and EPUB.

Why convert documents to Markdown for LLMs?

Markdown strips away visual formatting and keeps clean structure — headings, lists, tables — which language models parse more reliably than PDFs or binary office formats.
